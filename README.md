# Kimberly's XV — The Season (Bridgerton edition)

A Regency / Bridgerton-themed animated thank-you page for the guests of Kimberly's
quinceañera (August 29, 2026). Built by REGO Agency. Sister version of
[kimberly-xv-gracias](https://github.com/Rolz-Royz/kimberly-xv-gracias), same photos and music.

**Live:** https://rolz-royz.github.io/kimberly-xv-bridgerton/

- Opens with a hand-delivered letter: break the blue wax seal and it unfolds
- Kimberly's video inside a gilded oval mirror over a Regency garden
- "The Society Papers" gossip sheet that spins in, cameo portrait reveal,
  a hanging portrait gallery, dance cards, a velvet-curtain surprise dance,
  fireworks for the hora loca, oval miniatures and an embroidered thank-you card
- Background music (looping excerpt of Zoé — "Luna", MTV Unplugged)
- English / Spanish toggle, full-screen photo viewer

Not indexed by search engines (see `robots.txt` and the `noindex` meta tag).

## Local preview

    node server.js     # http://localhost:4610

Add `?open` to the URL to skip the letter animation.
